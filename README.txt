# StudyUp – Installierbare Lern-App

## Inhalt
- `index.html`: die App
- `manifest.webmanifest`: Angaben für „Zum Startbildschirm hinzufügen“
- `sw.js`: Offline-Cache
- `icon.svg`: App-Symbol

## Wichtig
Die App muss über eine HTTPS-Adresse geöffnet werden, damit Installation und Offline-Funktion funktionieren. Eine HTML-Datei direkt aus Downloads zu öffnen reicht dafür nicht.

## Einfacher Weg mit GitHub Pages
1. Auf GitHub ein neues Repository erstellen (z. B. `studyup`).
2. Die vier Dateien aus diesem Ordner hochladen (nicht den ZIP-Ordner selbst).
3. In den Repository-Einstellungen unter **Pages** die Veröffentlichung über den Branch `main` und Ordner `/ (root)` aktivieren.
4. Die angezeigte HTTPS-Adresse auf dem Samsung-Handy in Chrome öffnen.
5. In Chrome oben rechts auf **⋮** tippen und **App installieren** oder **Zum Startbildschirm hinzufügen** wählen.
6. StudyUp über das neue Symbol öffnen.

## Speicherung
Aufgaben, Streak und Noten werden lokal im Browser-Speicher auf diesem Gerät abgelegt. Sie werden nicht mit einem Konto synchronisiert. Browserdaten löschen oder ein Gerätewechsel kann die Daten entfernen. Für wichtige Noten empfiehlt sich eine zusätzliche Sicherung.

## Nutzung
- Start: Tagesaufgaben abhaken und den Tag abschließen.
- Plan: Wochenfokus und eigene Aufgaben verwalten.
- Lernen: kurze Erklärtexte und Mini-Tests zu acht Fächern.
- Noten: Noten pro Fach eintragen.
- Videos: öffnet eine YouTube-Suche zum aktuellen Thema.

Die Beispiel-Wochenplanung ist ein Startvorschlag und noch kein importierter persönlicher Stundenplan.
